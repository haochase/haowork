# 治理边界

TeamAI 分发 Skill、Rule、Agent；Haowork 持有 Mission、Scope、Context、审批、结构化回执与完成事实；AgentTeams 负责执行。本模板是独立团队资产仓库的复制起点，不是 Haowork 生产配置，也不表示腾讯与 Haowork 联合开发。

所有 Skill 先读取实际治理状态。缺有效 Mission、受限 Scope、可追溯 Context 或完成条件就停止。不得自批、扩大 Scope、伪造角色。只有经认证的 Delivery Leader 按真实服务端合同提交候选回执；高风险审批和最终验收归 Human。

禁止复制真实密钥、私有地址、人员资料、聊天或制品到资产仓库。不配置自动调用外部服务或写入治理状态的 Hook/MCP。TeamAI learning 不自动成为 Requirement、Evidence、Approval 或完成事实。
