# 独立团队资产

从仓库的 `examples/teamai-haowork-team/` 复制团队资产到自己管理的新仓库，再人工填写真实仓库 URL。该目录是模板引用，不是已分发或已安装证明。模板中的 example.invalid 必须替换，否则标记 BLOCKED_TEAM_REPO，不执行绑定。

TeamAI 自身的 `teamai.yaml` 管理团队来源与分发；项目 `.haowork/teamai.yaml` 是 Haowork 期望的资产声明，两者不能互相代替。只对实际安装资产生成 SHA-256。TeamAI Skill 是指导材料，不授予服务端身份、Lease、Scope 或审批权限。
